# Coffee Shop Report

## Overview

A **dynamic, premium‑styled web dashboard** that visualises sales, inventory, and performance metrics for a coffee shop. Built with vanilla HTML, CSS, and JavaScript, the project demonstrates modern UI/UX techniques (glassmorphism, micro‑animations, custom typography) while keeping the stack lightweight.

---

## Repository

```
git@github.com:Alwin-krn/coffee-shop-report.git
```

## Features

- **Elegant UI** – vibrant gradients, dark‑mode ready, smooth hover effects.
- **Interactive Charts** – responsive charts built with Chart.js.
- **Data Import** – CSV upload to feed sales data.
- **Export** – Download reports as PDF.
- **Responsive** – Works on desktop, tablet, and mobile.

---

## Getting Started

### Prerequisites

- **Node.js (>=18)** – for running the development server.
- **npm** – comes with Node.

### Installation

```bash
# Clone the repository
git clone git@github.com:Alwin-krn/coffee-shop-report.git
cd coffee-shop-report

# Install dependencies (only dev server tools)
npm install
```

### Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:3000`.

---

## Building for Production

When you are ready to deploy:

```bash
npm run build
```

The compiled static files will be placed in the `dist/` folder and can be served by any static‑file web server (e.g., Nginx, GitHub Pages).
